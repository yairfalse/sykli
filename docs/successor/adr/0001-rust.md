# ADR-0001: Rust

Status: accepted, 2026-08-04.

## Context

The reference implementation is Elixir/OTP (~50k lines engine, ~31k tests).
The BEAM earned its place there: supervised parallel task execution, PubSub
fanning occurrences to renderers and stores, daemons holding heartbeat state,
a coordinator serving HTTP.

The successor deletes every one of those surfaces (ADR-0005). What remains is
a single-run CLI: parse, execute, write receipts, exit. The OTP dependency
list and the deletion list are the same list.

Meanwhile the ecosystem consolidated on Rust: teko, toimija, kisko, ahti,
ruuma, and the shared `false-agent-protocol` crate (framing, work/worker
types, receipt refs). A shared guardrails standard exists for "any False
Systems Rust repository". Distribution of the Elixir binary (escript needs
Erlang; Burrito is heavy) has been a recurring tax; the family's repos embed
`sykli.rs` pipeline files already.

## Decision

Rust, edition 2024, MSRV aligned with the family (1.85). Single crate plus a
dev-only `xtask`, per family convention. Depend on `false-agent-protocol` for
shared composition types where they fit; never fork its vocabulary. Adopt the
shared Rust guardrails standard and CI gate shape used by teko/toimija.

Async runtime only if the executor demonstrably needs it; a thread-pool
scheduler is the default assumption for a process-spawning executor.

## Consequences

- The rewrite is a transcription, not a rediscovery: the ExUnit suite is the
  executable spec for scheduler ordering, cache keys, delta selection, and
  failure classification. Port the cases before the code.
- Elixir remains a first-class family language where it earns its keep
  (vartio). The Elixir SDK returns later as an emitter only (ADR-0003).
- BEAM idioms translate deliberately: behaviours → traits (Runtime port),
  "let it crash" → typed error values, pattern-matched parse/validate split →
  serde + a distinct validation pass.
- Static binaries make `install.sh <tag>` the entire distribution story.
